# MANILA - Página web de restaurante

## Descripción del proyecto

MANILA es una aplicación web desarrollada con Angular como proyecto académico, cuyo propósito es representar el funcionamiento y la presencia digital de un restaurante mediante una interfaz intuitiva, organizada y adaptable a diferentes dispositivos.

La aplicación integra diferentes secciones que permiten explorar el catálogo de comidas y bebidas, consultar productos mediante búsquedas y filtros, y gestionar pedidos desde un carrito de compras.

## Funcionalidades principales

- **Página de inicio:** presentación del restaurante y navegación entre las diferentes secciones.
- **Catálogo de comidas:** consulta de productos, búsqueda por nombre e ingrediente.
- **Catálogo de bebidas:** visualización y clasificación de bebidas mediante consultas a una API externa.
- **Carrito de pedidos:** agregar productos, modificar cantidades, eliminar elementos y calcular el total.
- **Formulario de pedidos:** registro de datos del cliente, tipo de entrega, método de pago y observaciones.
- **Recibos PDF:** generación y descarga de comprobantes con el resumen del pedido.
- **Juego interactivo:** sección de entretenimiento integrada en la página.

## Tecnologías utilizadas

- Angular
- TypeScript
- HTML5
- CSS3
- APIs REST
- LocalStorage
- jsPDF

## Almacenamiento

El proyecto utiliza LocalStorage para conservar los productos del carrito y el historial de pedidos en el navegador. No cuenta actualmente con un servidor backend ni una base de datos centralizada.

## Objetivo

Aplicar conocimientos de desarrollo web, programación con Angular, consumo de servicios externos, manejo de datos, diseño de interfaces y desarrollo de funcionalidades interactivas en un proyecto práctico.
